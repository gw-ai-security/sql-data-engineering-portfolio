# EDA Query Catalog

This catalog maps the implemented SQL to the question it answers. It is designed as a fast review path for a recruiter or technical reviewer: each analytical claim points back to executable repository evidence.

## 01 - Database Exploration

Script: [`../scripts/01_database_exploration.sql`](../scripts/01_database_exploration.sql)

| Question | Evidence | Concepts |
|---|---|---|
| What objects exist in the database? | query against `INFORMATION_SCHEMA.TABLES` | metadata discovery |
| What columns describe `dim_customers`? | query against `INFORMATION_SCHEMA.COLUMNS` | column metadata |

## 02 - Dimension Exploration

Script: [`../scripts/02_dimension_exploration.sql`](../scripts/02_dimension_exploration.sql)

| Question | Evidence | Concepts |
|---|---|---|
| Which countries are represented in the customer dimension? | `DISTINCT country` | domain discovery |
| What is the product hierarchy? | distinct category, subcategory and product name | hierarchy/granularity |
| How can the hierarchy be reviewed coherently? | ordered dimension values | `ORDER BY` |

## 03 - Date Range Exploration

Script: [`../scripts/03_date_range_exploration.sql`](../scripts/03_date_range_exploration.sql)

| Question | Evidence | Concepts |
|---|---|---|
| What are the first and last order dates? | `MIN(order_date)`, `MAX(order_date)` | temporal boundaries |
| How far apart are the order-date boundaries? | `DATEDIFF` | interval reasoning |
| What are the oldest and youngest birthdates? | `MIN/MAX(birthdate)` | date profiling |
| What age estimate does that imply at query time? | `DATEDIFF(YEAR, birthdate, GETDATE())` | time-dependent derived metric |

## 04 - Measure Exploration

Script: [`../scripts/04_measure_exploration.sql`](../scripts/04_measure_exploration.sql)

| Question | Evidence | Concepts |
|---|---|---|
| What are total sales and quantity? | `SUM` | additive measures |
| What is average selling price? | `AVG` | aggregate measure |
| How many sales lines and distinct orders exist? | `COUNT` vs. `COUNT(DISTINCT ...)` | grain awareness |
| How many products and customers exist? | dimension counts | entity counts |
| How many customers placed an order? | distinct fact customer keys | participation count |
| How can core metrics be returned in one result? | `UNION ALL` metric report | compatible result sets |

## 06 - Ranking Analysis

Script: [`../scripts/06_ranking_analysis.sql`](../scripts/06_ranking_analysis.sql)

| Question | Ranking pattern |
|---|---|
| Which five products generate the highest revenue? | `TOP 5` + descending revenue |
| Which five products generate the lowest revenue? | `TOP 5` + ascending revenue |
| Which subcategories generate the highest/lowest revenue? | change the ranking dimension |
| How can top products be selected with a window function? | `ROW_NUMBER()` + subquery filter |
| Which ten customers generate the highest revenue? | customer revenue ranking |
| Which three customers placed the fewest distinct orders? | ascending distinct-order count |

## Review Note

The EDA scripts are intentionally small and composable. The learning objective is not query length; it is choosing the correct grain, dimension, measure, aggregation and ordering for the question being asked.
