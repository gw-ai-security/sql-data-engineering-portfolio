# Acknowledgements

This portfolio track is based on the **SQL Data Warehouse** and **SQL Data Analytics** project sequence taught by **Data with Baraa (Baraa Khatib Salkini)** as part of his SQL course materials.

The original learning project provides the baseline scenario, datasets, project sequence, and reference implementation used for study and comparison.

This repository is maintained as an **independent implementation and learning record**. Its purpose is to document the engineering process rather than republish the reference repository as original work.

The work maintained here includes:

- independent implementation of the SQL tasks;
- architecture reasoning and decision records;
- project requirements and planning documentation;
- validation and data-quality evidence;
- Git history created during the implementation process;
- later portfolio extensions where they provide genuine engineering value.

Where the project intentionally follows the reference architecture or supplied datasets, that relationship is stated explicitly in the documentation.

## Attribution Principle

The distinction used throughout the repository is:

```text
Course/reference material
        ↓
Learning baseline and comparison
        ↓
Independent implementation, review, documentation and extensions
```

The original Data with Baraa project materials remain the authoritative source for the course project itself.
